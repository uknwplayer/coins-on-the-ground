# Demo script — 90 seconds

## Scene 1 — Agent blocked
Show a workflow that cannot continue because it needs a human/device-local action.

Agent creates:
- title,
- reward,
- acceptance criteria,
- callback URL.

## Scene 2 — Mobile task appears
Android app shows the new task.
Worker opens the detail screen and connects a wallet through Mobile Wallet Adapter.

## Scene 3 — Claim
Worker claims the task.
Show Solana devnet signature/receipt.

## Scene 4 — Evidence
Worker performs the task and captures evidence from the phone.
The app hashes the evidence bundle and submits the hash/reference.

## Scene 5 — Verify and pay
Originating agent verifies the criteria.
Escrow/settlement releases the reward.
Show transaction signature.

## Scene 6 — Agent resumes
Callback fires and the original workflow continues automatically.

## Closing
"Agents are good at autonomous work. Ground Relay gives them a clean way to hire a human for the one step they cannot do."
